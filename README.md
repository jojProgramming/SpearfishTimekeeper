# Spearfish Timekeeper
Timekeeper is an project designed to run on a Raspberry Pi 2 Zero W with the Pimoroni Breakout garden, BME688 Sensor Add on (I2C), and OLED SPI 1"12 (SPI).

## Connectivity
When you run the software, you can select (through command line arguments) a station and weather location to display live data for. Weather data includes temperature and description. Darwin Train API requires a key, which should be stored in the same folder as the script inside api_key.txt
